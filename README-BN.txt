يَوْمِيَّات — ইয়াওমিয়্যাত

এটি একটি ইনস্টলযোগ্য PWA (Android Chrome থেকে Home Screen-এ যোগ করা যায়)।

চালু করার জন্য:
1. HTTPS-এ হোস্ট করুন (যেমন GitHub Pages / Netlify) অথবা লোকাল ওয়েব সার্ভারে চালান।
2. Android Chrome-এ সাইট খুলুন → ⋮ → Add to Home screen / Install app.
3. প্রথমবার ৪–৮ সংখ্যার PIN তৈরি করুন।
4. প্রতিদিনের তথ্য তারিখ নির্বাচন করে পূরণ করুন এবং সেভ করুন।

সুবিধা:
- দৈনিক, সাপ্তাহিক ও মাসিক ক্যাটাগরি
- তারিখ অনুযায়ী রেকর্ড লোড ও এডিট
- নামাজের সংখ্যা ও লক্ষ্যভিত্তিক শতাংশ
- আয়-ব্যয়, ডায়েরি, ৫০০ শব্দের গুরুত্বপূর্ণ ঘটনা
- মাসিক রিপোর্ট ও A4 Print / Save as PDF
- PIN gate, Night mode, font size control
- JSON Backup / Restore
- Offline cache (প্রথমবার অনলাইনে খোলার পর)

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এই বিল্ডে স্বয়ংক্রিয় Google Sign-In / Cloud Sync নেই। PIN কেবল অ্যাপের সামনে প্রবেশ-নিয়ন্ত্রণ; এটি ডেটা এনক্রিপ্ট করে না।
- রেকর্ড এই ডিভাইসের browser storage-এ থাকে। ব্রাউজারের ডেটা মুছে গেলে রেকর্ড হারাতে পারে। তাই নিয়মিত JSON Backup ডাউনলোড করে Google Drive-এ রাখুন এবং নতুন ডিভাইসে Restore করুন।
- PDF-এর জন্য মাসের হিসাব খুলে ⋮ → A4 PDF / প্রিন্ট → Print dialog-এ Save as PDF নির্বাচন করুন।
